# Landing Page Design Prompt — "রিজেকশন ফাইল" Ebook
**For Figma (manual design or Figma AI / First Draft)**

---

## 0. PRODUCT CONTEXT (Figma AI-কে এই context দিন)

Product: বাংলা ইবুক — "রিজেকশন ফাইল: বাংলাদেশি স্টুডেন্ট ভিসা রিফিউজ হওয়ার ৪৭টি কারণ এবং প্রতিটি সমাধান"
Author brand: স্বাধীন
Audience: বাংলাদেশি স্টুডেন্ট যারা UK/Canada/Australia স্টুডেন্ট ভিসার জন্য apply করছে বা যাদের ভিসা রিফিউজ হয়েছে
Core promise: প্রতিটি রিফিউজাল কারণের পেছনে থাকা exact ডকুমেন্ট সমাধান — যাতে দ্বিতীয়বার (বা প্রথমবারই) ভিসা রিফিউজ না হয়
Price: [আপনার আসল দাম বসান] · Guarantee: ১০,০০০ টাকা মানি ব্যাক (শর্তসহ)
Format: Digital PDF, delivered via bKash/Nagad payment flow

---

## 1. OVERALL DESIGN DIRECTION

- **Style:** Trust-first, editorial-serious (visa/legal-adjacent বলে glossy sales-page look না দিয়ে "document/report" feel আনুন — যেমন official-looking letterhead, stamp, folder icon motifs)
- **Color palette:** Deep navy/maroon (authority, official feel) + off-white/cream background (paper texture hint) + one alert-red accent (শুধু urgency/scarcity element-এ)
- **Typography:** Bangla-supporting serif for headlines (Tiro Bangla / Noto Serif Bengali) — legal-document feel; sans-serif (Hind Siliguri / Noto Sans Bengali) for body
- **Mobile-first** — ৯০%+ traffic Facebook Ads থেকে মোবাইলে আসবে ধরে design করুন
- **Visual motifs:** stamped "REJECTED" red stamp graphic, folder/file icon, checklist checkmarks, document icons — বইয়ের নিজের visual identity (রিজেকশন ফাইল) কে ধরে রাখুন

## 2. PAGE SECTIONS (top to bottom)

### Section 1 — Hero
- Headline (pattern interrupt, না জেনে ভয় পাওয়ানো noise না — specific fact দিয়ে শুরু): 
  *"প্রতিটি ভিসা রিফিউজালের পেছনে ৪৭টার একটা কারণ থাকে — আপনারটা কোনটা, আপনি জানেন?"*
- Subheadline: বইয়ের core promise এক লাইনে — "কাগজ নয়, প্রমাণ। প্রতিটি রিফিউজাল কারণের exact সমাধান, ডকুমেন্ট লিস্টসহ।"
- Hero visual: বইয়ের mockup (3D book/PDF cover) + একটা "REJECTED" stamp graphic পাশে (visual hook)
- Primary CTA button: "এখনই বইটি সংগ্রহ করুন — ৳[price]"
- Micro-trust line নিচে: "✅ ১০,০০০ টাকা মানি ব্যাক গ্যারান্টি ✅ Instant PDF Delivery ✅ bKash/Nagad Payment"

### Section 2 — Problem Agitation (Angle: Problem Awareness)
বইয়ের ভূমিকা থেকে নেওয়া বাস্তব cost tুলে ধরুন:
- IELTS ফি, এপ্লিকেশন ফি, ব্যাংকে জমা টাকার সুযোগ-ব্যয়, কনসালটেন্সি ফি, টিউশন ডিপোজিট — এসব হারানোর ভয়
- Stat-style callout boxes (visual): "সবচেয়ে বড় ভুল? একটাই — সত্য থাকলেও ভুলভাবে উপস্থাপন করা"
- এখানে emotional pull থাকবে কিন্তু বইয়ের নিজের ethical framing অনুসরণ করুন: fear না, clarity দিন

### Section 3 — Authority / Why Trust This Book
- 47 কারণ, 6 অধ্যায়ের structure — icon grid দিয়ে visualize করুন (📄 টাকার কাগজ ১২টি, 🎤 SOP-ইন্টারভিউ ১০টি, ইত্যাদি)
- "প্রতিটি সমাধান সরকারি ডকুমেন্টেশনের ভিত্তিতে লেখা" — trust badge style
- লেখক পরিচিতি (Sadhin/স্বাধীন brand) সংক্ষেপে — যিনি এই লিখেছেন তার credibility

### Section 4 — What's Inside (Table of Contents visual)
- ৬ অধ্যায় + ৬ অ্যানেক্স কে একটা visual "file/folder" layout এ দেখান
- প্রতিটা অধ্যায়ে কয়টা কারণ কভার করে তা number badge দিয়ে দেখান
- Bonus annexes আলাদা highlight করুন (Annex C: Source of Funds টেমপ্লেট, Annex D: Gap Explanation টেমপ্লেট, Annex F: এজেন্ট বাছাইয়ের ১২ প্রশ্ন) — এগুলো "ready-to-use templates" হিসেবে sell করুন, এটা high-value USP

### Section 5 — Who This Is For / Not For
Two-column layout (✅ / ❌) — বইয়ের নিজের "কার জন্য / কার জন্য নয়" section থেকে সরাসরি নিন। এটা objection handling + qualifies the buyer, trust বাড়ায়।

### Section 6 — Social Proof (Video + Text Reviews)
- Video testimonial carousel — 3 স্লট রাখুন placeholder সহ (student/family video reviews, বাংলায়)
- এর নিচে text review cards (star rating + name + city, যেমন "রাকিব, ঢাকা" + short quote)
- **⚠️ Design note:** এই section টা placeholder হিসেবে বানান — real reviews collect করার আগে এখানে "শীঘ্রই আসছে" বা empty state রাখুন, publish করবেন না fake data দিয়ে

### Section 7 — The Guarantee
Dedicated section, badge/seal visual দিয়ে:
- "১০,০০০ টাকা মানি ব্যাক গ্যারান্টি"
- নিচে ৩ লাইনে exact শর্ত লিখুন (কবে পর্যন্ত claim করা যাবে, কীভাবে claim করবে, কী condition-এ) — vague guarantee legally এবং trust-wise দুর্বল, specific একটা লিখুন
- Risk-reversal framing: "বই পড়ে যদি মনে হয় ভ্যালু পাননি, টাকা ফেরত — ঝুঁকি আমাদের"

### Section 8 — Offer Stack + Pricing
- Value stack (bullet with strikethrough perceived value → actual price):
  - মূল ইবুক (৪৭ কারণ + সমাধান) — ৳[value]
  - Annex C, D, F টেমপ্লেট bundle — ৳[value]
  - [যদি থাকে] Bonus checklist PDF — ৳[value]
  - **Total value: ৳[X] → আজকের দাম: ৳[actual price]**
- CTA button: "এখনই অর্ডার করুন"
- Payment icons: bKash, Nagad logo

### Section 9 — Upsell / Order Bump

**Product: "এডিটেবল ডকুমেন্ট টেমপ্লেট প্যাক" (Word + Excel, fully editable)**

Logic: বইয়ের Annex C (Source of Funds Declaration), Annex D (Study Gap Explanation), Annex B (Master Document Checklist) — এগুলো PDF-এ static template হিসেবে আছে। Order bump হলো এই একই templates-এর **editable Word/Excel version** — যেখানে ইউজার সরাসরি নিজের নাম, তারিখ, অ্যামাউন্ট বসিয়ে ফেলতে পারবে, retype করতে হবে না। এটা বইয়েরই content থেকে বানানো বলে production cost প্রায় শূন্য, কিন্তু perceived value বেশি (সময় বাঁচায়) — order bump এর জন্য আদর্শ।

**অন্তর্ভুক্ত থাকবে:**
- Source of Funds Declaration — editable Word template (Annex C ভিত্তিতে)
- Study Gap Explanation Letter — editable Word template (Annex D ভিত্তিতে)
- Master Document Checklist — editable Excel/Google Sheet (Annex B ভিত্তিতে, টিক দেওয়া যাবে, progress % দেখাবে)
- Bonus: "Bank Statement বনাম Requirement" auto-calculator (Excel — কাণ ২ ও ৩ থেকে অনুপ্রাণিত simple formula)

**Suggested price:** মূল বইয়ের দামের প্রায় ২০-৩০% (যেমন বই ৳৩৯৯ হলে বাম্প ৳৯৯-১২৯) — order bump সবসময় impulse-price রেঞ্জে রাখা ভালো, চিন্তা করার সময় যেন না লাগে

**Copy (checkbox card):**
> ☐ হ্যাঁ, আমি সাথে **এডিটেবল ডকুমেন্ট টেমপ্লেট প্যাক** (Word + Excel) নিতে চাই — মাত্র +৳[১২৯] (আলাদা কিনলে ৳[৩৫০])
> *PDF-এর টেমপ্লেট নিজে টাইপ করে বানাতে হবে না — সরাসরি ফিলাপ করে জমা দিন।*

**Format/placement:** Pricing section-এর ঠিক নিচে, checkout button-এর আগে — checkbox pre-selected/unselected দুটোই A/B test করা যায়। Visually main product card-এর চেয়ে ছোট, halka border, hard-sell language avoid করুন (order bump impulse decision, pressure না)

### Section 10 — FAQ (Objection Handling angle)
Accordion component, বইয়ের ভাষাতেই:
- "এই বই কি ভিসা গ্যারান্টি দেয়?" → না দেয় না, but explain করে কেন এটা essential ধাপ
- "আমি PDF কীভাবে পাবো?"
- "রিফান্ড কীভাবে কাজ করে?"
- "এজেন্ট থাকলেও কি এই বই লাগবে?"

### Section 11 — Urgency / Scarcity
- সৎভাবে করুন — fake countdown avoid করুন যদি real না হয়। Options:
  - Price বাড়বে এমন real deadline থাকলে countdown timer
  - অথবা "Bonus templates শুধু এই সপ্তাহের অর্ডারে" — bonus-based urgency (কম risky, believable)
- Sticky mobile CTA bar (bottom fixed): "এখনই সংগ্রহ করুন — ৳[price]" — scroll করলেও থাকবে

### Section 12 — Final CTA + Footer
- শেষ emotional push, বইয়ের নিজের line ব্যবহার করতে পারেন: "সৎ ফাইল, সম্পূর্ণ ফাইল, সাজানো ফাইল — এই তিনটাই যথেষ্ট।"
- Footer: Refund policy link, Contact (WhatsApp/Facebook page), copyright, disclaimer line (বইয়ের নিজের disclaimer অনুসারে — এটা legal/immigration advice না)

## 3. UX / CONVERSION NOTES

- CTA button একই color/style সব জায়গায় repeat করুন — pattern recognition
- প্রতিটা major section-এর পর soft CTA repeat করুন (হার্ড sell না, "বিস্তারিত জানুন" থেকে "এখনই নিন" এ gradient করে বাড়ান)
- Guarantee badge hero section-এই ছোট করে দেখান, পরে বড় section এ elaborate করুন — early trust signal
- Mobile: single column, thumb-friendly button size (min 48px height), sticky CTA bar must

## 4. TONE FOR COPY (যখন content লিখবেন)

- বইয়ের নিজের tone অনুসরণ করুন: sober, evidence-based, "ভয় দেখানো" না বরং "clarity দেওয়া" — এইটাই আসলে বেশি trust তৈরি করে এবং conversion-এও ভালো কাজ করে কারণ এই audience (visa-rejected/anxious) already emotionally charged, বাড়তি hype তাদের skeptical করে তুলবে
- Specific numbers/facts ব্যবহার করুন (৪৭ কারণ, ৬ অধ্যায়, ২৮ দিন maintenance period ইত্যাদি) — vague claim না
